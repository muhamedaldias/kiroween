# GhostSpec

A haunting, polished property-based test generator driven by Kiro specs. Paste a spec, get fast-check tests. Built for Kiroween 2026 (Costume Contest).

## Features
- Spec → property-based tests (fast-check)
- Deep module core: `parseSpec` / `generateTests`
- Haunting dark-mode UI with motion
- Kiro spec-driven development, hooks, steering, custom agent, MCP

## Run
```
npm install
npm run dev
npm test
npm run build
```

See `docs/kiro-usage.md` and `/.kiro`.
